# 📊 FNP Sales Analysis Dashboard

## 📌 Project Overview
This project focuses on analyzing FNP sales data using Microsoft Excel. The dashboard provides insights into revenue trends, customer spending behavior, product performance, and occasion-wise sales using interactive visualizations.

---

## 🛠️ Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Dashboard Design

---

## 📈 Key Metrics

| Metric | Value |
|----------|----------|
| Total Orders | 2 |
| Total Revenue | ₹7,692 |
| Avg Days Between Order & Delivery | 5.5 |
| Avg Customer Spending | ₹3,846 |

---

## 📊 Dashboard Features

### Revenue Analysis
- Revenue by Occasion
- Revenue by Category
- Revenue by Product
- Revenue by City
- Revenue by Hour
- Revenue by Month

### Interactive Filters
- Order Date Slicer
- Occasion Slicer

## 🎯 Key Insights

- Anniversary generated the highest revenue.
- Cake category contributed the highest sales.
- Occaecati Gift was the top-performing product.
- Average customer spending was ₹3,846.
- Sales data was analyzed across cities, products, and occasions.
